Скорректированный Roadmap

Двухфазный план с фокусом на быстрый запуск основного функционала (Phase 1) и последующее добавление B2B-сети (Phase 2).

Phase 1: MVP (Фокус на ядро)

Итого: ~2 месяца

  • Milestone 1.1 (1 нед): Настройка инфраструктуры (Docker, Supabase, Cloudflare, n8n)
  • Milestone 1.2 (2 нед): Интеграция с каталогом (exist.ru) для получения артикулов
  • Milestone 1.3 (3 нед): Настройка парсинга (Playwright+MCP) для 3-5 поставщиков
  • Milestone 1.4 (2 нед): Настройка AI-Анализа (Gemini) для генерации рекомендаций
  • Milestone 1.5 (1 нед): Создание Telegram-бота для менеджера (команды, отчеты)

Phase 2: B2B Сеть (Упрощенная)

Итого: ~3 недели

  • Milestone 2.1 (2 нед): Telegram-бот для магазинов (регистрация, broadcast, ответы)
  • Milestone 2.2 (1 нед): Интеграция B2B-ответов в основной поиск менеджера
