## 📋 Переформулировка: Вопросы для исследования

### **Вопрос 1: Белорусская специфика каталогов**

**Суть проблемы:**
- exist.ru работает с Россией, нам нужен белорусский рынок
- По данным Perplexity есть: auto1.by, armtek.by, zapchasti24.by, av-parts.by
- У них есть API (или хотя бы структурированный поиск)

**Что нужно выяснить у менеджера:**
- ❓ Какими каталогами он **реально** пользуется сейчас?
- ❓ Какие белорусские поставщики самые популярные?
- ❓ Есть ли у этих поставщиков открытые API или нужна договоренность?
- ❓ Как часто встречается ситуация "артикул есть в каталоге, но у поставщика другой номер"?

**Риски:**
- ⚠️ API может требовать коммерческих договоров (не просто так отдадут)
- ⚠️ Может не быть вообще никакого API, только сайт для ручного поиска
- ⚠️ Разные поставщики могут использовать разную логику каталогизации

### **Вопрос 2: Проблема не-заводских артикулов**

**Суть проблемы:**
Некоторые поставщики могут использовать **свою внутреннюю номенклатуру** вместо стандартных заводских артикулов.

**Примеры из практики (нужно проверить с менеджером):**

```
Сценарий А: Поставщик использует OEM артикулы
✅ Заводской артикул Toyota: 04152-YZZA6
✅ У всех поставщиков тот же: 04152-YZZA6
✅ Проблемы нет - просто парсим

Сценарий Б: Поставщик использует свою номенклатуру
❌ Заводской: 04152-YZZA6
❌ У "АвтоМагБел": AM-F-1234 (их внутренний код)
❌ Поиск по заводскому артикулу не работает
❌ Нужен маппинг или база соответствий
```

**Что нужно выяснить:**
- ❓ Насколько часто это встречается? (редко = можно вручную, часто = нужна автоматизация)
- ❓ Публикуют ли поставщики таблицы соответствий?
- ❓ Как менеджер решает это сейчас? (звонит? ищет в прайсе вручную?)
- ❓ Есть ли прайс-листы в Excel с этими маппингами?

**Возможные решения (для обсуждения):**
1. **Ручной маппинг:** Менеджер сам заполняет таблицу соответствий (трудозатратно, но точно)
2. **Прайс-листы:** Загружаем Excel от поставщиков в систему (твой RAG может это)
3. **AI-распознавание:** Пытаемся найти соответствия через описание детали (рискованно, может ошибаться)

### **Вопрос 3: Применимость твоего RAG-решения**

**Твои наработки (если я правильно понял):**

```
Google Drive → n8n → Supabase

Поддерживает:
├── Текстовые документы (txt, md, pdf, docx)
│   └── Создаются embeddings для семантического поиска
│
└── Excel таблицы
    └── Загружаются как JSON + схема извлечения
    └── Можно делать SQL-запросы
```

**Потенциальные кейсы для PartScout:**

#### Кейс 1: Прайс-листы поставщиков (Excel)
```
Файл: АвтоМагБел_прайс_январь2025.xlsx

Колонки:
[Артикул OEM | Артикул поставщика | Название | Цена | Наличие | Ссылка]

Что с этим делать:
✅ Загрузить в Supabase через твой n8n
✅ SQL запросы: "Найти все позиции с артикулом 04152-YZZA6"
✅ Аналитика: "Средняя цена за последний квартал"

Вопрос к менеджеру:
- Как часто обновляются прайсы? (каждый день = парсинг актуальнее, раз в месяц = загружаем в базу)
- В каком формате их присылают? (Excel, PDF, вообще нет прайсов?)
```

#### Кейс 2: База знаний о совместимости (документы)
```
Файл: СовместимостьФильтров.md

Содержимое:
"Масляный фильтр 04152-YZZA6 подходит для:
- Toyota Camry V50 (2011-2017)
- Toyota Camry V55 (2014-2018)
- Lexus ES350 (2012-2018)

Аналоги:
- Mann W610/3
- Mahle OC606
- Bosch 0451103336"

Что с этим делать:
✅ Векторный поиск при вопросе "Подойдет ли этот фильтр на ES350?"
✅ AI может найти в контексте и ответить

Вопрос к менеджеру:
- Есть ли у него подобная база знаний? (блокнот, заметки, опыт в голове?)
- Готов ли он вести такие документы? (или это лишняя работа?)
```

#### Кейс 3: История проблемных случаев
```
Файл: ПроблемныеСлучаи.txt

"15.01.2025 - Клиент заказал тормозные диски для BMW X5.
Поставщик "АвтоПлюс" прислал не те (перепутал артикулы).
Решение: больше не заказываем тормозную систему у "АвтоПлюс"."

Что с этим делать:
✅ RAG может это учесть при рекомендациях
✅ "АвтоПлюс" будет ниже в рейтинге для тормозов

Вопрос к менеджеру:
- Ведет ли он такой учет? (обычно нет)
- Хочет ли вести? (может быть полезно для бизнеса)
```

**Оценка применимости твоего RAG:**

| Кейс | Нужно для MVP? | Сложность внедрения | Зависит от данных |
|------|----------------|---------------------|-------------------|
| Прайс-листы Excel | ✅ ДА (если есть) | 🟢 Низкая | Поставщики должны давать прайсы |
| База знаний | ⏳ Опционально | 🟡 Средняя | Менеджер должен заполнять |
| История проблем | ❌ Phase 2 | 🟢 Низкая | Нужно время накопить данные |
