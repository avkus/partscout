# 🎯 Архитектурный анализ проекта

Отличная бизнес-идея! Разберем по полочкам.

## 💡 Название проекта (варианты)

1. **PartsFinder AI** - прямолинейно, понятно
2. **AutoPartsPilot** - акцент на автоматизацию
3. **PartScout** - короткое, ёмкое
4. **SpareSync** - синхронизация поставщиков
5. **QuickPart Hub** - акцент на скорость

**Мое предложение: `PartScout`** - короткое, запоминающееся, отражает суть (разведка запчастей)

---

## 🎯 Декомпозиция на модули

### **Модуль 1: "Каталог и нормализация"**
- Получение корректных артикулов по VIN/марке авто
- Интеграция с exist.ru, Emex и др. каталогами
- Поиск аналогов и кросс-номеров

### **Модуль 2: "Мониторинг поставщиков"**
- Парсинг/браузинг сайтов поставщиков
- Сбор данных: цена, наличие, сроки
- Кэширование и актуализация данных

### **Модуль 3: "AI Аналитик"**
- Анализ собранных данных
- Формирование рекомендаций
- Генерация отчетов (PDF/структурированный формат)

### **Модуль 4: "Локальная сеть поставщиков"**
- Telegram бот для магазинов
- Система broadcast запросов
- Агрегация ответов в реальном времени

### **Модуль 5: "Интерфейс менеджера"**
- Telegram бот/веб-интерфейс для сотрудников
- История запросов
- Быстрые ссылки на поставщиков

## 🗺️ ROADMAP (4 фазы)

### **PHASE 1: MVP (2-3 месяца)** 🎯
**Цель:** Проверить гипотезу с минимальными затратами

**Что делаем:**
- ✅ Модуль 1: Интеграция с 1-2 каталогами (exist.ru)
- ✅ Модуль 2: Browser-based поиск на 3-5 ключевых поставщиках
- ✅ Модуль 3: Простой AI анализ с GPT-4o
- ✅ Модуль 5: Telegram бот для менеджера (базовый)

**Метрики успеха:**
- Корректность определения артикула: >90%
- Скорость обработки запроса: <5 минут
- Удовлетворенность менеджера: экономия >30% времени

---

### **PHASE 2: Оптимизация (1-2 месяца)** ⚡
**Цель:** Ускорить и удешевить

**Что делаем:**
- 🔄 Гибридная система: база данных + браузинг для популярных деталей
- 🔄 Расширение до 10-15 поставщиков
- 🔄 Улучшение AI промптов и добавление thinking визуализации
- 🔄 Интеграция n8n для автоматизации рутинных задач

**Метрики:**
- Снижение стоимости запроса на 40%
- Скорость: <2 минуты

---

### **PHASE 3: B2B сеть (2 месяца)** 🤝
**Цель:** Создать локальную экосистему

**Что делаем:**
- 🆕 Модуль 4: Telegram бот для сторонних магазинов
- 🆕 Система рейтингов поставщиков
- 🆕 Аналитика: какие детали чаще нужны локально
- 🆕 Базовая монетизация (комиссия или подписка для магазинов)

---

### **PHASE 4: Масштабирование (3+ месяца)** 🚀
**Цель:** Выход за пределы одного автосервиса

**Что делаем:**
- 📈 Multi-tenancy: SaaS для других шиномонтажек
- 📈 Мобильное приложение
- 📈 Интеграция с CRM и учетными системами
- 📈 Предиктивная аналитика спроса

## 🛠️ Технологический стек (рекомендации)

### **Backend**
```
Python 3.11+ (основной язык)
├── FastAPI (API, быстрый, async)
├── Celery + Redis (очереди задач, кэш)
├── SQLAlchemy + PostgreSQL (основная БД)
└── Alembic (миграции)
```

**Почему:**
- Python - экосистема для AI/парсинга
- FastAPI - производительность + автодокументация
- PostgreSQL - надежность, JSONB для гибких данных

### **AI & Automation**
```
AI Layer
├── Anthropic Claude (via MCP) - для сложного анализа
├── OpenAI GPT-4o - для генерации отчетов
├── LangChain/CrewAI - оркестрация агентов
└── Model Context Protocol (MCP) - стандартизация

Automation
├── n8n (low-code workflows)
├── Browser Use / Playwright (браузинг)
└── Apache Airflow (опционально, для сложных DAG)
```

**Почему:**
- MCP - современный стандарт, переиспользование компонентов
- n8n - визуальная настройка без кода для менеджера
- Browser Use - специализация на AI-управлении браузером

### **Data Collection**
```
Scraping Stack
├── Playwright (динамический контент)
├── BeautifulSoup4 / lxml (статика)
├── ScrapingBee API (резервный, для защищенных сайтов)
└── Selenium Grid (если нужна масштабируемость)
```

### **Messaging & Notifications**
```
├── python-telegram-bot (Telegram API)
├── Aiogram (альтернатива, более async)
└── RabbitMQ (опционально, для очередей сообщений)
```

### **Storage**
```
PostgreSQL (основное)
├── Справочники (каталоги деталей)
├── История запросов
└── Данные магазинов

Redis
├── Кэш цен (TTL 1-24ч)
├── Celery broker
└── Rate limiting

S3 / MinIO
└── PDF отчеты, скриншоты
```

### **Frontend (опционально)**
```
├── React / Next.js (если нужен веб-интерфейс)
├── shadcn/ui (компоненты)
└── TailwindCSS (стили)
```

### **DevOps**
```
├── Docker + Docker Compose (контейнеризация)
├── GitHub Actions (CI/CD)
├── Grafana + Prometheus (мониторинг)
└── Sentry (ошибки)
```

## 🤔 Ключевые архитектурные решения

### **1. Парсинг: Гибридный подход**

```
┌─────────────────────────────────────┐
│ Входящий запрос (артикул детали)   │
└───────────────┬─────────────────────┘
                │
        ┌───────▼────────┐
        │ Проверка кэша  │
        │ (Redis, 6ч TTL)│
        └───┬────────┬───┘
            │        │
     Есть   │        │  Нет
        ┌───▼──┐  ┌──▼──────────────┐
        │ Отдать│  │ Проверка частоты│
        │ кэш   │  │ запросов (БД)   │
        └───────┘  └──┬──────────┬───┘
                      │          │
               Частая │          │ Редкая
            ┌─────────▼──┐  ┌────▼────────┐
            │ Запрос в   │  │ Browser Use │
            │ локальную  │  │ real-time   │
            │ БД (парсинг│  │ парсинг     │
            │ по расписанию)│              │
            └────────────┘  └─────────────┘
```

**Критерий "частоты":** >3 запросов за последние 30 дней

### **2. AI Pipeline**

```
┌─────────────────────────────────────┐
│ Собранные данные (15 поставщиков)  │
└───────────────┬─────────────────────┘
                │
        ┌───────▼────────────┐
        │ MCP: Preprocessor  │
        │ (нормализация)     │
        └───────┬────────────┘
                │
        ┌───────▼────────────┐
        │ AI Agent: Analyzer │
        │ (Claude 3.5)       │
        │ - Сравнение цен    │
        │ - Оценка рисков    │
        │ - Расчет доставки  │
        └───────┬────────────┘
                │
        ┌───────▼────────────┐
        │ AI Agent: Reporter │
        │ (GPT-4o)           │
        │ - Генерация PDF    │
        │ - Структура данных │
        └───────┬────────────┘
                │
        ┌───────▼────────────┐
        │ Отправка менеджеру │
        │ (Telegram)         │
        └────────────────────┘
```

### **3. B2B Telegram бот - архитектура**

```
Менеджер                     Магазины (10-20)
    │                              │
    │ "Нужна деталь X"             │
    ▼                              │
┌────────────┐                     │
│PartScout   │ ──broadcast───────► │
│Bot         │                     │
└────────────┘                     │
    ▲                              │
    │     ┌─────────────────────┐  │
    │     │ Магазин А: Да, 500₽│ ◄┘
    │     │ Магазин Б: Нет      │
    │     │ Магазин В: Да, 480₽│
    │     └──────────┬──────────┘
    │                │
    └────────────────┘
    (агрегация за 5 мин)
```

**Монетизация для магазинов:**
- Freemium: 10 запросов/мес бесплатно
- Pro: 300₽/мес безлимит получение
- Premium: 500₽/мес + возможность самим делать broadcast
